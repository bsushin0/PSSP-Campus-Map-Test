Situations Test

How the test runs

The evaluator runs and judges each scenario. The overall result is a pass when a majority of scenarios pass. The evaluator may request one more scenario.

Topics

Each topic is one kind of situation. A topic marked Key points not confirmed shows the evaluator a warning. Untick it once you have checked the list against the training. The checklist is the answer key the evaluator sees: one item per line.

Checks on every scenario

One per line. These appear under every topic's checklist.

Details the site picks from

When a scenario is drawn, the site picks a place from the map test's buildings and streets, and describes the individuals and vehicles from these lists. One entry per line.
