The codes list

One code per line, four parts separated by | : kind, code, correct meaning, other accepted answers (separated by ;, optional). Kind is 10-code or signal. Answers are not case sensitive, punctuation is ignored, and a small typo is forgiven.

The offline copy in SharePoint (PSSP-Radio-Codes-Test.html) keeps its own list. After you save here, make the same change in that file and archive the old one, as the admin guide describes.
