PSSP Vault Setup

Run this file on your own computer by double-clicking it. Nothing you type or load is sent anywhere. Do not upload this file's inputs (private-data.json) or the key file to GitHub.

How the protection works

Two things are needed to open anything: a password and a secret key file. The key file is random and long, so even a short password such as PSSPAdmin cannot be guessed from what is posted on GitHub. Keep the key file in your private SharePoint admin folder, never in the repository.

First-time setup

Three files download:

  1. pssp-keyfile.txt: the secret key file. Store it in your private SharePoint admin folder and give it only to admins. Do not upload it to GitHub.
  2. private.enc.json: the encrypted building and street names. Upload to the main folder of the repository.
  3. vault-key.json: the vault's public key. Upload to the main folder of the repository.

Later: update the test data only

Use this when you get a new private-data.json (for example, after a map change). It keeps your key file and vault, so saved results stay readable.
